# AI4Sci 2026 talk

Quarto revealjs slides (15 min + 5 min Q&A). All numbers and figures are
computed at render time from the installed `binnr` package and its bundled
benchmark results, so re-rendering after a benchmark rerun updates the talk.

    quarto render slides.qmd          # -> slides.html (open in a browser; press E for PDF export)

`slides.pdf` was exported from the HTML with a headless browser.
